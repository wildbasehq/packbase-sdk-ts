---
title: pb.dm
description: List direct-message conversations, send messages, and load older or newer messages.
---
`pb.dm` manages direct messages for the signed-in user. A **channel** is one conversation, and a **message** is one item inside it. Every method on this page requires authentication.

The examples use placeholder UUIDs. Replace values such as `'channel-uuid'` and `'target-user-uuid'` with IDs returned by Packbase.
## Methods overview
| Method | Description |
| --- | --- |
| `pb.dm.channels()` | List all DM channels for the current user |
| `pb.dm.channel(id)` | Get a `ChannelHandle` for a specific channel |
| `pb.dm.open(userId)` | Open or get an existing 1:1 channel with a user |
| `pb.dm.deleteMessage(messageId)` | Delete a DM message |
## `pb.dm.channels()`: List channels
Fires `GET /dm/channels`.
```ts
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
const myUserId = 'my-uuid'
// ---cut---
const channels = await pb.dm.channels()
//    ^?

for (const channel of channels) {
  const other = channel.recipients.find(r => r.id !== myUserId)
  console.log(`DM with ${other?.username}: ${channel.unread_count} unread`)
}
```
**Returns:** `Promise<DMChannel[]>`
## `pb.dm.channel(id)`: Get a channel handle
Returns a `ChannelHandle` without making a network request. A handle is a small object tied to one channel ID. Await it to fetch the channel itself, or call `.messages()` and `.send()` directly when you don't need the channel details first.
```ts
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
const handle = pb.dm.channel('channel-uuid')
//    ^?
```
### `await handle`: Fetch channel
Fires `GET /dm/channels/:id`.
```ts
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
const channel = await pb.dm.channel('channel-uuid')
//    ^?

console.log(channel.recipients)
console.log(channel.unread_count)
```
**Returns:** `Promise<DMChannel>`
### `handle.messages(options?)`: Fetch messages
Fires `GET /dm/channels/:id/messages`. Messages are returned newest-first by default, so the first item is the most recent.
```ts
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
const messages = await pb.dm.channel('channel-uuid').messages({ limit: 50 })
//    ^?

// Older messages (cursor-based with message IDs)
const older = await pb.dm.channel('channel-uuid').messages({
  before: messages.at(-1)?.id,
})

// Newer messages (for polling new arrivals)
const newer = await pb.dm.channel('channel-uuid').messages({
  after: messages[0]?.id,
})
```
**Options:**
| Option | Type | Description |
| --- | --- | --- |
| `limit` | `number` | Max messages to return. |
| `before` | `string` | Return messages before this message ID. |
| `after` | `string` | Return messages after this message ID. |
**Returns:** `Promise<DMMessage[]>`
### `handle.send(content, options?)`: Send a message
Fires `POST /dm/channels/:id/messages`.
```ts
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
// Simple message
const msg = await pb.dm.channel('channel-uuid').send("Hey, what's up?")
//    ^?

// Reply to another message
const reply = await pb.dm.channel('channel-uuid').send("That's great!", {
  replyTo: 'message-uuid',
})
console.log(msg.id)
console.log(msg.created_at)
```
**Returns:** `Promise<DMMessage>`
## `pb.dm.open(userId)`: Open a 1:1 channel
Fires `POST /dm/channels`. If a one-to-one channel already exists with that user, Packbase returns it. Otherwise, it creates one. Callers don't need to check for an existing conversation first.
```ts
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
const channel = await pb.dm.open('target-user-uuid')
//    ^?

console.log(channel.id)
// Now send a message
await pb.dm.channel(channel.id).send('Hello!')
```
Self-DMs are supported, so `userId` may also be your own UUID.
**Returns:** `Promise<DMChannel>`
## `pb.dm.deleteMessage(messageId)`: Delete a message
Fires `DELETE /dm/messages/:id`. You can only delete messages you sent.
```ts
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
await pb.dm.deleteMessage('message-uuid')
```
**Returns:** `Promise<void>`
