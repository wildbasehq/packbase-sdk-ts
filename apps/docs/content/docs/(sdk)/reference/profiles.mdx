---
title: pb.profiles
description: Fetch profiles, follow or unfollow users, and submit reports.
---

Call `pb.profiles(username)` with a Packbase username to get a lazy `ProfileHandle`. This action does not make a network request. Await the handle to fetch the profile. Alternatively, call an action such as `.follow()` directly. The action does not fetch the profile first.

## Fetch a profile

```ts twoslash
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
const profile = await pb.profiles('rek')

console.log(profile.display_name)
console.log(profile.about?.bio)
```

The result is a [`Profile`](/types/profile). Some properties are optional because public and authenticated requests can receive different data.

## Follow and unfollow

Following and unfollowing are separate server operations:

```ts twoslash
import { PackbaseSDK } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
await pb.profiles('rek').follow()   // POST /user/:username/follow
await pb.profiles('rek').unfollow() // DELETE /user/:username/follow
```

Both methods finish without response data (`Promise<void>`). If you follow an account that you already follow, the server returns status `400`. The server returns the same status if you unfollow an account that you do not follow.

## Report a user

```ts twoslash
import { PackbaseSDK, ReportReason } from '@packbase/sdk-ts'
const pb = new PackbaseSDK()
// ---cut---
const ticket = await pb.profiles('rek').report(
  ReportReason.Spam,
  'Repeated unsolicited posts.',
)

console.log(ticket.id, ticket.status)
```

This sends `POST /user/:username/report` and returns a `ReportResult`.
