Update user settings. howl_like_emoji is one Unicode emoji or an available Pack emote token (default 🔥) used only for newly created howls; existing howl emojis remain unchanged. allow_tag_edits_from_others is a boolean that defaults to true, allowing other signed-in members to edit unlocked tags on existing and future howls. False limits ordinary editing to the author; staff/content moderators retain their permissions. All edits require public explanations and create public tag history. Unavailable custom like emotes reset to 🔥 with one inbox notice; published howl emojis remain unchanged.
