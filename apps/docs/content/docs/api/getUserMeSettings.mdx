Read user settings. howl_like_emoji is one emoji (default 🔥) used only for newly created howls; existing howl emojis remain unchanged. allow_tag_edits_from_others is a boolean that defaults to true, allowing other signed-in members to edit unlocked tags on existing and future howls.
